# SpatialHunt — MVP vs Future Scope

- Account creation (tenant / landlord)
- Email/phone verification **UI** (backend delivery TODO)
- Landlord KYC / verification wizard (NIN + docs + walkthrough) → existing verification APIs
- Property creation wizard (photos + walkthrough URL)
- Search/browse + filters (public properties UI; API available)
